# ボタン操作の調査・修正（2026-09-17）

## 対象と方針

修正前の `src` 内にある30ファイル・88箇所の `<button>` 定義を確認した。
繰り返し描画されるカード・プレイヤー・リアクションは定義単位で集計。
フォームの Enter 送信、コヨーテのダブルタップ、ボタン風のリンクも確認対象。

- 通信を伴う操作は、再描画前から有効な ref のロックと、処理中表示・無効化を併用する。
- 共通 `PendingButton` は高速に完了した操作の二度目のクリックと、キー長押しも抑制する。
- 失敗時は既存のエラー表示または共通エラー表示を使い、ロックを解除して再試行可能にする。
- 選択・開閉・数値変更など即時に結果が見える操作は、連続操作を維持する。
- コヨーテの意図したダブルタップは維持し、その後の通信の重複を防ぐ。

## 検証と範囲

追加した回帰テストは、再描画前の重複実行、競合する操作、失敗後の再試行、部屋作成後の遷移待ち、ヘッダーとゲーム内の復帰処理の共有、ボタンの表示・無効化、連続クリック、キー長押し、リンクの待機表示と修飾キー操作を確認する。

フロントエンドでの同一画面の重複操作を対象としており、複数端末からの同時更新や、サーバー処理済みの応答が失われた後の再送を保証する変更ではない。DBマイグレーションは変更していない。
